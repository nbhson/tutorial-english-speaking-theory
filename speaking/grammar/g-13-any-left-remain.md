# Grammar 13 — Be there any + N + left / remain? (Còn không?)

> **Nhóm D: MẠO TỪ & ĐỊNH LƯỢNG**

---

## I. CẤU TRÚC

`Is/Are there + any + N + left/remaining?`

| Số ít | Số nhiều |
|-------|---------|
| **Is there** any **milk** left? | **Are there** any **apples** left? |
| **Is there** any **time** remaining? | **Are there** any **seats** left? |

**Trả lời:**
- ✅ *Yes, there's some left.* / *Yes, there are a few.*
- ❌ *No, there isn't any left.* / *No, there aren't any left.* / *We ran out.*

**Phản xạ nói:** *Is there* → /ɪz ðər/ → **"izder"**; *Are there* → /ɑːr ðər/ → **"arther"**

## II. KHI NÀO DÙNG?

- Hỏi **thực phẩm / đồ đạc còn không** trong nhà / cửa hàng.
- Hỏi **ghế / chỗ ngồi còn không** ở rạp chiếu phim, nhà hàng.
- Hỏi **thời gian / tiền bạc còn không**.
- Dùng trong shop, nhà hàng, siêu thị hàng ngày.

### ⚠️ Lỗi thường gặp
- ~~There is any left?~~ → *Is there any left?* — câu hỏi phải đảo lên đầu.
- ~~Are there any milk left?~~ — milk không đếm được → *Is there any milk left?*
- ~~Is there some left?~~ trong câu hỏi — dùng **any** trong hỏi/phủ định, **some** trong khẳng định.

## III. NGỮ PHÁP CHI TIẾT

### Left vs Remaining

| Từ | Sắc thái | Ví dụ |
|----|---------|-------|
| **Left** | Informal, thông dụng hơn | *Is there any pizza left?* |
| **Remaining** | Formal, trang trọng hơn | *Is there any time remaining?* |

**Phản xạ hỏi–đáp:**
- ❓ Hỏi: `Is there any coffee left?` *(Café còn không?)*
- ➕ Đáp: *Yeah, there's a little left in the pot.* — *Ừ, còn chút trong ấm.*
- 💬 Đáp lại: *Can I have a cup?*

**Ví dụ:**
1. Is there any bread left? — *Còn bánh mì không?*
2. Are there any tickets left for the concert? — *Còn vé cho buổi hòa nhạc không?*
3. Is there any milk remaining in the fridge? — *Trong tủ lạnh còn sữa không?*
4. Are there any questions left? — *Còn câu hỏi nào không?*
5. There aren't any seats left — the movie is full. — *Không còn chỗ ngồi đâu — phim đầy rồi.*

**Biến tấu (tự luyện):**
- Đổi N: *Is there any water left?*
- Đổi thì: *Were there any cookies left yesterday?*

### Nhầm "any" (số đếm được) vs "some" (khẳng định / mời)

| Tình huống | Dùng | Ví dụ |
|-----------|------|-------|
| Câu hỏi thông thường (chưa biết) | **any** | *Is there any milk left?* |
| Câu hỏi mà bạn mong đợi "có" / mời | **some** | *Would you like some coffee?* |
| Câu khẳng định | **some** | *There's some bread left.* |
| Câu phủ định | **any** | *There isn't any bread left.* |

> 💡 **Mẹo:** Khi **mời** ai đó (đặc biệt trong quán cà phê, nhà hàng) → dùng **some** dù là câu hỏi: *Would you like **some** water?*

## VI. LUYỆN NÓI

### Echo drill (nói to 3 lần, nhanh hơn mỗi lần)
1. *Is there any milk left?*
2. *Are there any tickets left for the concert?*
3. *We ran out of bread this morning.*
4. *Is there still some coffee left?*
5. *Nothing left — let's go to the store.*

### 5 câu hỏi tự luyện
1. Is there any food left in the fridge? — *Yes, there's …* / *No, we ran out…*
2. Are there any seats left at the cinema? — *Yes, there are …* / *No, it's full.*
3. Is there any time left? — *Yes, we still have …* / *No, time's up.*
4. Are there any cookies left? — *Yes, there are …* / *I ate them all!*
5. Is there still some water in the bottle? — *Yes, there's …* / *No, it's empty.*

> ✅ **Checkpoint:** Trả lời 5 câu trên **không nhìn note**. Ghi âm và tự nghe lại.

---

**Ngữ cảnh thực tế:**
- Đi làm: *Are there any files left?* / *Is there any budget remaining?* / *Any tasks left?* / *How much time is left?*
- Du lịch: *Are there any seats left?* / *Is there any time remaining?* / *Any tickets left?* / *How much money is left?*
- Mua sắm: *Are there any in stock?* / *Is there any discount left?* / *Any sizes left?* / *How much is remaining?*

**Ví dụ thực tế thêm (6 câu):**
1. Are there any tickets left? — *Còn vé không?*
2. Is there any food left? — *Còn đồ ăn không?*
3. How much time is left? — *Còn bao nhiêu thời gian?*
4. There's nothing left. — *Không còn gì cả.*
5. Are there any seats remaining? — *Còn chỗ ngồi không?*
6. There's a little money left. — *Còn một ít tiền.*

## VII. BONUS: SOME vs ANY — Quy tắc nhanh

| | **Some** | **Any** |
|--|---------|---------|
| Khẳng định | ✅ *There's some milk.* | — |
| Phủ định | — | ✅ *There isn't any milk.* |
| Câu hỏi | ⚠️ khi mong đợi "yes" | ✅ *Is there any milk?* |
| Đề nghị | ✅ *Would you like some coffee?* | — |

> 💡 Mẹo: Trong câu hỏi, nếu bạn **mong đợi câu trả lời "có"** (đề nghị, mời), dùng **some**. Nếu hỏi thông tin thực sự, dùng **any**.
